# Проектная документация: Система ТОиР производственного цеха

## Тема
**«Проектирование корпоративной индустриальной системы управления техническим обслуживанием и ремонтом оборудования (ТОиР) производственного цеха»**

Система управления заявками на ремонт и техническое обслуживание оборудования небольшого производственного цеха (10–15 единиц основного оборудования).

**Основные функции:** регистрация заявок диспетчером, назначение исполнителей, контроль выполнения, учёт использованных запчастей, формирование отчётов.  
**Роли:** Диспетчер, Инженер, Мастер, Начальник участка, Администратор ИС, Специалист по ИБ, Аналитик.

## Цель
Сформировать полный комплект проверяемой проектной документации, обеспечивающий управляемый и воспроизводимый процесс создания информационной системы — от предпроектного обследования и формализации требований до детального UML-моделирования структуры, поведения, взаимодействий и процессов, готовый к передаче на этап реализации и тестирования.

## Практическая работа №1 — Организация процесса проектирования ИС
- **Что сделано:** Спроектирован процесс проектирования ИС.
- **Ключевые результаты:**
  - Выбрана нормативная база: **ГОСТ 34.601-90** + **ISO/IEC 12207**.
  - Определены 6 стадий (от обследования до ввода в действие), для каждой заданы входы, выходы и измеримые результаты.
  - Составлены матрица ответственности (RACI), план работ, правила управления изменениями и реестр из 10 рисков.
  - Построена матрица трассируемости требований к этапам и артефактам.
- **Главный итог:** Комплект документов, по которому другой человек может понять, как именно ведётся проектирование.

  - Сформированы функциональные (FR-01..FR-05) и нефункциональные требования (NFR-01..NFR-04).

## Технологический стек

|------|-----------|
| Backend API | ASP.NET Core 8, C# 12 |

| Секреты | HashiCorp Vault |

| CASE-средство | Visual Paradigm |
| Нормативная база | ГОСТ 34.601-90, ISO/IEC 12207 |
